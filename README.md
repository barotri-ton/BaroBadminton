# BaroBadminton 3D

Vietnamese-first browser badminton simulation.

## Development

The project is under active development. Gameplay, equipment specifications, and online multiplayer must not be represented as complete without test evidence.

## Language

All player-facing text is Vietnamese (`vi-VN`). Source code and technical identifiers are English.

## Disclaimer

Unofficial fan project. Not affiliated with or endorsed by badminton equipment manufacturers.
